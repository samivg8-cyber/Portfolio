# Project 1 – Windows Server Administration

## Project Overview

This project was completed as part of my Windows Server coursework at Valencia College. The project involved building and documenting a Windows Server environment for the fictional domain "Inn Of The Last Home."

## What I Built

I configured a multi-server Windows Server environment that included a domain controller, DHCP server, file server, and Windows client.

The project included Active Directory Domain Services (AD DS), organizational units, users and groups, DHCP, file sharing, File Server Resource Manager (FSRM), Group Policy Objects (GPOs), and Windows Admin Center.

## Skills Demonstrated

Windows Server administration

Active Directory Domain Services (AD DS)

DNS

DHCP

Organizational Units (OUs)

User and group management

File server configuration

File and folder permissions

File Server Resource Manager (FSRM)

Group Policy

Windows Admin Center

Network troubleshooting

Virtual machine configuration

## Project Documentation

I created network, Active Directory, and shared folder diagrams to document the environment. I also documented the server configurations, client machine, DHCP setup, file server, shared folders, Group Policy settings, and Windows Admin Center.

## What I Learned

This project helped me become more comfortable working with Windows Server and understanding how different server roles work together. I practiced configuring Active Directory, managing users and groups, setting up DHCP, creating shared resources, applying Group Policy, and testing connectivity between machines.
