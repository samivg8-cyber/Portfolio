# Project 2 – Windows Server Network Project

## Project Overview

This project was completed as part of my Windows Server coursework at Valencia College. The project involved creating and documenting a Windows Server network based on a fictional Wizarding World environment.

## What I Built

I configured three Windows Server machines and a Windows client.

Server 1 was configured with Active Directory Domain Services (AD DS) and DNS. Server 2 was configured with AD DS and DHCP. Server 3 was configured as a File Server Resource Manager (FSRM) server.

I also created organizational units, groups, and users for Gryffindor, Ravenclaw, and Slytherin. The Windows client received its IP configuration through DHCP and was connected to the network.

## Project Configuration

The environment included three Windows Server machines and one Windows client.

The first server provided AD DS and DNS. The second server provided AD DS and DHCP. The third server was configured for FSRM and file server functions.

The client machine was configured to use DHCP and connected to the network.

## What I Learned

This project gave me more hands-on practice building a Windows Server network. I learned how Active Directory, DNS, DHCP, file servers, and client computers work together.

I also practiced creating users and groups, organizing users with organizational units, configuring shared folders, and testing connectivity between machines.
