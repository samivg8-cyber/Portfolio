Welcome to my professional portfolio. I am a Cybersecurity student at Valencia College building hands-on experience in IT, system administration, networking, and information security.

The project includes Active Directory Domain Services, DNS, DHCP, organizational units, users and groups, a Windows client, File Server Resource Manager, and shared folders.
